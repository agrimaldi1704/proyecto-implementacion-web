# CyberShield – Cybersecurity Company Landing Page

Responsive landing page for a fictional cybersecurity company, built as a course project for *Implementación y Diseño Web* at Escuela Bancaria y Comercial (EBC).

**Live demo:** https://agrimaldi1704.github.io/proyecto-implementacion-web/

## Features
- Responsive navbar and image carousel (Bootstrap 5)
- Dynamic greeting based on the time of day
- Services section with alert-style cards and collapsible accordion
- Contact form with client-side validation
- Interactive counter
- Scroll animations with AOS

## Built with
HTML5 · CSS3 · JavaScript · Bootstrap 5 · Bootstrap Icons · AOS

## Run locally
Download the repository and open `index.html` in your browser. No installation required.

## Note
CyberShield is a fictional company created for educational purposes. The contact details in the footer belong to the author.
